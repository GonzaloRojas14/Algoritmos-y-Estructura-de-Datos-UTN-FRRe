## 2 · QUÉ ES UNA PILA

**QUÉ ES UNA PILA**

Una **pila** (del inglés *stack*) es una lista lineal y dinámica en la que la **inserción y eliminación de elementos se realiza solo por un extremo**, llamado tope (TOS — Top Of Stack).

```
[■■■] ── Apilar ──╮   ╭── Desapilar ──→ [■■■]
                  ↓   │
                [■■■■■■■]
                [■■■■■■■]
                [■■■■■■■]
                [■■■■■■■]
                [■■■■■■■]
                [■■■■■■■]
```

*Dibujo: una pila de bloques azules (más claros hacia abajo); un bloque entra por arriba ("Apilar") y otro sale por arriba ("Desapilar").*

El principio de funcionamiento es
**LIFO** (*Last In, First Out*)
***El último elemento en entrar es el primero en salir.***

> [!important]
> En una pila, solo se puede acceder al **elemento superior**, lo que la diferencia de las listas generales, donde se puede recorrer o modificar cualquier posición.

## 3 · INSERTAR Y ELIMINAR EN UNA PILA

**INSERTAR Y ELIMINAR EN UNA PILA**

```
Acción PUSH (TOPE: puntero a Nodo; x: [tipo de dato]) es
   Nuevo(Q);
   Q^.dato := x;
   Q^.prox := TOPE;
   TOPE := Q;
FinAcción
```

```
Acción POP (TOPE: puntero a Nodo) es
   Si TOPE <> NIL entonces
      Aux := TOPE;
      TOPE := TOPE^.prox;
      Disponer(Aux);
   Sino
      Escribir("Pila vacía");
   FinSi;
FinAcción
```

*En la filmina, `PUSH` y `POP` están en negrita.*

```
                 ↓           ↓           ↓           ↑
 │     │     │     │     │     │     │ [3] │     │ [3] │
 │     │     │     │     │ [2] │     │ [2] │     │ [2] │
 │     │     │ [1] │     │ [1] │     │ [1] │     │ [1] │
 └─────┘     └─────┘     └─────┘     └─────┘     └─────┘
  empty       push        push        push         pop
  stack
```

*Dibujo: secuencia de una pila vacía, tres push (1, 2, 3) y un pop que saca el 3 por arriba.*

## 4 · QUÉ ES UNA COLA

**QUÉ ES UNA COLA**

Una **cola** (del inglés queue) es una estructura de datos lineal en la que los elementos se **almacenan y se accede a ellos siguiendo el principio FIFO** (First In, First Out), es decir: el primero que entra es el primero que sale.

```
   ▮
   │                Final            Principio
   ╰──→  Encolar     ▮  ▮  ▮  ▮  ▮   ──╮  Desencolar
                                       ↓
                                       ▮
```

*Dibujo: una fila de bloques; uno nuevo entra por el "Final" ("Encolar") y otro sale por el "Principio" ("Desencolar").*

**Orden lineal**: los elementos tienen un orden definido, de izquierda a derecha, por ejemplo.

**Acceso restringido**: solo se puede:

- Insertar un elemento al final de la cola (**enqueue** o encolar).
- Extraer un elemento desde el frente de la cola (**dequeue** o desencolar).

**Primero en entrar, primero en salir (FIFO)**: el primer elemento insertado será el primero en salir.

**Tamaño variable**: puede ser fija (array) o dinámica (listas enlazadas).

## 5 · INSERTAR y ELIMINAR de una COLA

**INSERTAR y ELIMINAR de una COLA**

```
ACCION InsertaCola Es
Ambiente
 NODO = Registro
       dato: N(5)
       prox: Puntero a NODO
 FIN REG

 P, PRIM:Puntero a Nodo
 inserta:booleano

Proceso
//Inicializa puntero externo
  PRIM:=Nil

//Inserta nodos
Esc(‘Desea insertar elemento en la cola?’)
Leer(inserta)
Mientras inserta hacer
  Nuevo(P)
  Leer(*P.dato)
  Si PRIM = NIL entonces //caso lista vacía
    PRIM:=P
     Contrario
    Q:=PRIM
    Mientras *Q.prox <> Nil hacer //lista con elementos
       Q:=*Q.prox
    FinMientras

    *Q.prox:= P
  FinSi

    *P.prox:=Nil

    Leer(inserta)
FinMientras
FinACCION
```

> [!bug] Errata de la filmina
> `Q` se usa en el Proceso (`Q:=PRIM`, `Q:=*Q.prox`, `*Q.prox:= P`) pero **no está declarada** en el Ambiente, que sólo declara `P, PRIM` e `inserta`.

```
ACCION EliminaCola(PRIM:Puntero a Nodo) Es
Ambiente
 NODO = Registro
      dato: N(5)
      prox: Puntero a NODO
 FIN REG
 Q:Puntero a Nodo
 inserta:booleano

Proceso
Esc(‘Desea desencolar elemento en la cola?’)
Leer(inserta)

Mientras inserta hacer
  Si PRIM = NIL entonces //caso lista vacía
    ESC(“Error. Cola Vacía”)
   Contrario
    Q:=PRIM
    PRIM:=*Q.prox
    DISPONER(Q)  //Borra el elemento
  FinSi
    Leer(inserta)
FinMientras
FinACCION
```
