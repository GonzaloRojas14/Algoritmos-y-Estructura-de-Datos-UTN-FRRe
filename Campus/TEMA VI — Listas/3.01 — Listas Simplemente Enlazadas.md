## 5 · QUÉ SON LAS ESTRUCTURAS DINÁMICAS

**QUÉ SON LAS ESTRUCTURAS DINÁMICAS**

Las **estructuras de datos dinámicas** son aquellas que permiten **gestionar la memoria de manera flexible durante la ejecución del programa**, adaptándose al tamaño necesario en tiempo real.

Se gestionan a través de punteros, variables que se almacenan en memoria interna.

Esto es especialmente útil cuando no se conoce de antemano la cantidad de datos que se va a almacenar.

## 6 · QUÉ ES UNA LISTA ENLAZADA

**QUÉ ES UNA LISTA ENLAZADA**

> [!important] Definición
> Una **lista lineal o enlazada** es una **estructura de datos dinámica** donde los elementos, llamados **nodos**, se organizan secuencialmente y están conectados entre sí mediante **punteros**.

```
Estructura de un nodo ──→ ┌─────────────┬─────────┐
                          │    DATOS    │ ENLACE  │
                          └─────────────┴─────────┘
```

Cada nodo contiene dos partes:

1. **Dato**: El valor almacenado (que puede ser de cualquier tipo).
2. **Enlace**: Un puntero o enlace que señala al siguiente nodo en la lista.

```
[DATOS|•]─┐
          ↓
     [DATOS|•]─┐
               ↓
          [DATOS|•]──→ ═ (tierra / nulo)
```

## 8 · CÓMO CONSTRUYO UNA LISTA LINEAL

**CÓMO CONSTRUYO UNA LISTA LINEAL**

| **LISTAS DESORDENADAS** | **LISTAS ORDENADAS** |
|---|---|
| • *No hay orden* específico para los elementos. | • Los elementos se agregan para que la lista final tenga un *orden específico*. |
| • La lista se construye agregando cada *nuevo elemento al final* de la lista existente. | • Hay que buscar el *punto de inserción* del elemento según el orden establecido. |
| • Si la lista está vacía, el nuevo elemento pasa a ser el *primero y único* de la lista. | • La inserción puede ser al *principio*, en *medio* o al *final*. |
| | • Si la lista está vacía, el nuevo elemento pasa a ser el *primero y único* de la lista. |

## 14 · PUNTERO

**PUNTERO**

> [!important] Definición
> Un **puntero** es una variable que almacena la **dirección de memoria** de otro elemento almacenar directamente un valor.

En programación, los **punteros** permiten manipular datos en **diferentes ubicaciones de memoria**, facilitando operaciones dinámicas, como la creación de estructuras complejas (listas enlazadas, árboles, etc.) y el acceso eficiente a los datos.

```
                       Puntero Interno
Puntero   ┌───┐      ┌──────┬───┐     ┌──────┬───┐     ┌──────┬───┐
Externo   │ ● │────▶ │      │ ● │───▶ │      │ ● │───▶ │      │   │──┐
          └───┘      └──────┴───┘     └──────┴───┘     └──────┴───┘  │
                         Nodo                                     Nil │
                                                                    ═══
```

> [!note] Nota del transcriptor
> La frase "otro elemento almacenar directamente un valor" está así en la filmina (falta algo como "en lugar de"); se copia tal cual.

## 15 · PUNTEROS INTERNOS vs PUNTEROS EXTERNOS

**PUNTEROS INTERNOS vs PUNTEROS EXTERNOS**

**Punteros internos**: Son los punteros dentro de la estructura, como los enlaces entre nodos en una lista enlazada. Conectan un nodo con otros nodos de la lista, permitiendo el recorrido y las operaciones internas.

**Punteros externos**: Son punteros que se encuentran fuera de la estructura de datos y permiten acceder a ella desde el exterior, como el puntero que apunta al primer nodo (cabeza) de una lista enlazada

## 16 · CLASIFICACIÓN

**CLASIFICACIÓN**

```
         ┌─ Según cantidad de ──────┬─ LISTAS SIMPLEMENTE ENLAZADAS
         │  punteros internos       │
         │                          └─ LISTAS DOBLEMENTE ENLAZADAS
LISTAS ──┤
         │                          ┌─ CON EXISTENCIA DE NULIDAD
         └─ Según existencia o no ──┤
            de concepto de nulidad  └─ LISTAS CIRCULARES
```

| Tipo | Descripción |
|---|---|
| LISTAS SIMPLEMENTE ENLAZADAS | Cada nodo tiene un puntero que apunta al siguiente nodo. |
| LISTAS DOBLEMENTE ENLAZADAS | Cada nodo tiene dos punteros, uno al siguiente nodo y otro al anterior. |
| CON EXISTENCIA DE NULIDAD | Indican el final de la lista con un puntero que apunta a NULL. |
| LISTAS CIRCULARES | El último nodo apunta de nuevo al primer nodo, no existe nulidad. |

## 24 · ALGORITMO COMPLETO

**ALGORITMO COMPLETO**

```
PROCESO
  SI (PRIM = NIL) ENTONCES
       Caso_1 //Inserto en Lista Vacia
  SINO
        P := PRIM;
        ANT := NIL;

        //Quiero una lista ordenada de menor a mayor
        MIENTRAS (P <> NIL) ^ (*P.DATO < *Q.DATO) HACER
            ANT := P;
            P := *P.prox;
        FIN  MIENTRAS
    SI (P = PRIM) ENTONCES
      Caso_2 //Inserto en primer posición
    SINO
      Otro_caso //Inserto en el medio o al final

FIN ACCION;
```

*Captura 1 (izquierda):*

```c
#include <stdio.h>
#include <stdlib.h>

// Definición de la estructura del nodo
struct Nodo {
    int dato;
    struct Nodo* siguiente;
};

// Función para crear un nuevo nodo
struct Nodo* crearNodo(int valor) {
    struct Nodo* nuevoNodo = (struct Nodo*)malloc(sizeof(struct Nodo));
    nuevoNodo->dato = valor;
    nuevoNodo->siguiente = NULL;
    return nuevoNodo;
}
```

*Captura 2 (centro):*

```c
// Función principal
int main() {
    struct Nodo* cabeza = NULL;

    insertarAlInicio(&cabeza, 10);
    insertarAlInicio(&cabeza, 20);
    insertarAlInicio(&cabeza, 30);

    printf("Lista enlazada: ");
    imprimirLista(cabeza);

    return 0;
}
```

*Captura 3 (derecha):*

```c
// Función para insertar un nodo al inicio de la lista
void insertarAlInicio(struct Nodo** cabeza, int valor) {
    struct Nodo* nuevoNodo = crearNodo(valor);
    nuevoNodo->siguiente = *cabeza;
    *cabeza = nuevoNodo;
}

// Función para recorrer e imprimir la lista
void imprimirLista(struct Nodo* nodo) {
    while (nodo != NULL) {
        printf("%d -> ", nodo->dato);
        nodo = nodo->siguiente;
    }
    printf("NULL\n");
}
```

## 26 · BUSCAR UN ELEMENTO — CASO 1: Único nodo en la Lista

**BUSCAR UN ELEMENTO**
**CASO 1: Único nodo en la Lista**

```
PROCESO
  P:= PRIM

  Si *P.prox = NIL entonces

     Si *P.dato = buscado entonces
        Esc(‘El elemento buscado es el único elemento de la lista’)
     sino
        Esc(“No existe el elemento buscado en la lista’)
     FinSi

  FinSi
```

Llamadas de la filmina:

- `*P.prox = NIL` (resaltado) → **Hay un único nodo en la Lista**
- `*P.dato = buscado` (resaltado) → **Se encontró el elemento**
- `Esc(“No existe el elemento buscado en la lista’)` → **No se encontró el elemento**

> [!note] Nota del transcriptor
